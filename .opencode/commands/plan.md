Run **only the PLAN gate** (the Create stage).

Use the `plan` skill with `facilitation` (option menu). Requires `insight.yaml`.

1. **Anchor** — present ~4 candidate anchors (segment × job × moment); the team picks/remixes one → creative brief line.
2. **Scenario** — present ~8 candidate moments; the team picks 3–5 (time / place / event) and the creative spine.
3. **Idea** — present ~8 idea starters; the team picks 2–3 to build on / remixes / `+1 own`. Then converge (dot-vote) and deepen (1-2-4-All) → name + slogan + proposition.
4. **Pilot** — present a markets menu; the team picks **2** + success criteria.
5. **Budget** — present allocation slices; the team confirms the split of the MVP budget.
6. Output `plan.yaml` + `campaign-plan.html` (DOC_TYPE: "Campaign Plan" / "Membership Design").

Choice-first, human-led. Do not decide for the team.
