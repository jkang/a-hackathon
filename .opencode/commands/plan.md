Run **only the PLAN gate** (the creative heart). Use the `plan` skill + `facilitation` (option menu). Requires `insight.yaml` (key insights + selected insights).

1. **Brainstorm** — run `creative-concept`: anchor + reframe the selected insights into one HMW, then creative-thinking methods → **~6 candidate ideas** (name · one-line · insight · mechanic).
2. **Pick** — the team **selects 2–3** of the ~6, or **combines several** into a hybrid.
3. **Define + plan** — `opportunity-definition` (5 elements) + the campaign plan (positioning, offering, 4Ps, 2 pilot markets, budget).
4. **A/B** — produce **≥2 distinct plan versions**; the team **picks A or B**.
5. **Poster** — design the hero visual via the `poster` skill.

Choice-first, human-led. Do not decide for the team.
